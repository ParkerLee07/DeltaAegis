# DeltaAegis v1.0.2 Scan Orchestration Reliability

DeltaAegis v1.0.2 is a compatibility maintenance candidate coordinated with NetSniper v2.2.

## Permanent protections

- New additive migration `0006-v1.0.2-scan-orchestration` creates a partial SQLite unique index that prevents more than one `QUEUED` or `RUNNING` job from owning the same NetSniper executable and runs directory.
- Released migrations `0001` through `0005` remain byte-for-byte immutable, preserving compatibility with existing v1.0.0 and v1.0.1 migration ledgers.
- Existing `BEGIN IMMEDIATE` reservation remains the primary per-sensor serialization boundary.
- Enabling schedules automatically distributes equal-cadence schedules across the cadence window; subsequent completions and skips advance the existing phase instead of resetting from completion time.
- Scheduled TrueAegis follow-up verifies the source and retained manifests share the accepted `scan_id`, then executes against DeltaAegis's trusted retained manifest.

## Compatibility

No NetSniper telemetry schema bump is required. The candidate accepts `netsniper-run-v3` with scanner version `v2.2.0`, retains accepted evidence, rejects tampering, and preserves unknown/review classification behavior.
